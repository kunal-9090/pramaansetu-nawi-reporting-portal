# TrustGate for NAWI Reporting — Design System

## Direction
Professional Indian government digital-service style: official, calm, modern, minimal, highly readable and trustworthy. Never cartoonish, crowded or dependent on unofficial government marks.

## Tokens
Navy primary for authority and navigation; white/light blue surfaces; green for verified/pass/approved; orange for review/retest; red for missing evidence/non-compliance; grey for disabled/not applicable; restrained purple for TrustGate emphasis.

## Typography
Clean sans-serif, large page headings, readable table text, clear labels and generous line-height. Use one primary family with a limited display accent only if needed.

## Components
Sidebar navigation, header, summary cards, status badges, workflow stepper, evidence cards, reading table, alert boxes, decision panels, report preview card and audit timeline.

## Navigation
Dashboard; Create Case; Inspection Cases; NAWI Passport; Guided Tests; TrustGate Review; Officer Dashboard; Reports; Audit Trail; Settings.

## Experience rules
Use semantic headings and landmarks, visible focus, high contrast, status text in addition to color, concise helper copy and responsive stacking. The primary action should always communicate the next workflow step. Footer: “Evidence Before Result — every NAWI finding must be verified, traceable and officer-approved.”

## Premium upgrade rules
Use Inter/system sans-serif with a clear display scale, 8–14px spacing rhythm, 7–10px radii, restrained shadows, sticky navigation only where it improves orientation, and touch-safe 40px controls. Prefer light-blue guidance surfaces over gradients; reserve purple for TrustGate-specific emphasis. On mobile, collapse grids before they become cramped and let wide data tables scroll horizontally. Focus rings must remain visible for keyboard users.
